The archive contains the study's analytical records, synthetic tasks, and the passages actually supplied to the coders. API response identifiers and model names are historical provenance, not API credentials. Historical absolute paths are retained inside the run archive because they are part of the recorded execution history. The supported reproduction command resolves only repository-relative paths.
